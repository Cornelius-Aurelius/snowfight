# Snowfight

[**Play Snowfight**](https://cornelius-aurelius.github.io/snowfight/)

A Christmas arcade game by [Cornelius Aurelius](https://corneliusaurelius.com/).
Slide, fire chocolate buttons and take on the toy army across 40 levels.

Drag to move on touchscreens, or use the arrow keys or A/D on a keyboard.
Shots fire automatically. Clear a level to unlock the next one.
